# 数组方法

1. 手写 `map`
   - 考点：回调参数、返回新数组、不修改原数组。
   - 边界：稀疏数组、`thisArg`。

2. 手写 `filter`
   - 考点：按回调布尔结果收集元素。
   - 边界：稀疏数组、原数组不变。

3. 手写 `reduce`
   - 考点：累加器、初始值、回调参数。
   - 边界：空数组且没有初始值时抛错。

4. 手写 `forEach`
   - 考点：遍历副作用、无返回值。
   - 边界：无法通过 `return` 中断。

5. 手写 `find`
   - 考点：返回第一个满足条件的元素。
   - 边界：没有命中返回 `undefined`。

6. 手写 `some` / `every`
   - 考点：短路逻辑。
   - 边界：空数组时 `some` 为 false，`every` 为 true。

7. 手写数组扁平化 `flat`
   - 考点：递归、迭代、指定展开深度。
   - 边界：`Infinity`、稀疏数组。

8. 手写数组去重
   - 考点：`Set`、哈希表、排序去重。
   - 边界：`NaN`、对象引用、`+0` 和 `-0`。

9. 手写数组分组 `groupBy`
   - 考点：回调取 key、对象聚合、`Map` 聚合。
   - 边界：key 为对象时优先使用 `Map`。

10. 手写数组乱序 `shuffle`
    - 考点：Fisher-Yates 洗牌算法。
    - 边界：避免 `sort(() => Math.random() - 0.5)` 的随机偏差。
