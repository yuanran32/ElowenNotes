# 函数式工具

1. 手写函数柯里化 `curry`
   - 考点：参数缓存、递归返回函数、固定参数长度。
   - 边界：一次传多个参数、保留 `this`。

2. 手写偏函数 `partial`
   - 考点：预置参数、占位符参数。
   - 边界：剩余参数顺序。

3. 手写组合函数 `compose`
   - 考点：从右到左执行。
   - 边界：空函数列表、单函数列表。

4. 手写管道函数 `pipe`
   - 考点：从左到右执行。
   - 边界：异步函数可扩展为 `asyncPipe`。

5. 手写 `once`
   - 考点：函数只执行一次，缓存第一次结果。
   - 边界：第一次执行异常是否缓存，需要约定。

6. 手写 `memoize`
   - 考点：参数到结果的缓存。
   - 边界：对象参数序列化、缓存淘汰策略。
