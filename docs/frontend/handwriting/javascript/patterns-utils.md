# 设计模式与工具

1. 手写发布订阅 `EventEmitter`
   - 考点：`on`、`off`、`once`、`emit`。
   - 边界：监听器执行中解绑、重复监听、错误隔离。

2. 手写观察者模式
   - 考点：Subject、Observer、依赖收集、通知更新。
   - 边界：订阅清理，避免内存泄漏。

3. 手写单例模式
   - 考点：闭包缓存实例、类静态属性。
   - 边界：多参数初始化只以第一次为准。

4. 手写 LRU 缓存
   - 考点：`Map` 或哈希表加双向链表。
   - 边界：容量为 0、更新已有 key、访问后移动到最新。

5. 手写模板字符串解析
   - 示例：`render("hello {{name}}", { name: "Tom" })`
   - 考点：正则匹配、路径取值、默认值。

6. 手写对象路径访问 `get`
   - 示例：`get(obj, "a.b[0].c")`
   - 考点：路径解析、数组下标、默认值。

7. 手写对象路径设置 `set`
   - 示例：`set(obj, "a.b[0].c", 1)`
   - 考点：中间对象创建、数组路径处理。
