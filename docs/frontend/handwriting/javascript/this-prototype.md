# this 与原型

1. 手写 `call`
   - 考点：`this` 绑定、临时属性、参数透传、返回值。
   - 边界：`context` 为 `null` / `undefined`、基本类型装箱、Symbol key 防冲突。

2. 手写 `apply`
   - 考点：数组参数处理、`this` 默认绑定。
   - 边界：第二个参数不是数组或类数组、参数为空。

3. 手写 `bind`
   - 考点：函数柯里化、构造函数调用、原型继承。
   - 边界：`new` 调用时绑定 `this` 失效，但预置参数仍生效。

4. 手写 `new`
   - 考点：创建对象、原型绑定、执行构造函数、处理返回值。
   - 边界：构造函数返回对象或函数时直接返回该值。

5. 手写 `instanceof`
   - 考点：沿原型链查找 `constructor.prototype`。
   - 边界：左侧不是对象、右侧不是函数、跨 iframe 场景。

6. 手写 `Object.create`
   - 考点：以传入对象作为新对象原型。
   - 边界：原型只能是对象或 `null`。

7. 手写继承
   - 考点：原型链继承、构造函数继承、组合继承、寄生组合继承。
   - 边界：实例属性共享、构造函数重复调用。
