# 安全

1. 手写 XSS 转义函数
   - 考点：HTML 实体编码。
   - 边界：HTML 文本、属性、URL、CSS 不同上下文。

2. 手写 CSRF 防护示例
   - 考点：SameSite、CSRF token、自定义 header。
   - 边界：跨站表单、跨域请求。

3. 手写前端鉴权流程
   - 考点：token 存储、刷新 token、路由守卫。
   - 边界：多标签页登录态同步。

4. 手写权限控制
   - 考点：路由权限、菜单权限、按钮权限。
   - 边界：前端权限只做体验，后端必须校验。

5. 手写敏感信息脱敏
   - 考点：手机号、身份证、邮箱、姓名脱敏。
   - 边界：格式不合法时的处理。
