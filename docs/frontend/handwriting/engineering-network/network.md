# 网络

1. 手写 JSONP
   - 考点：script 标签跨域、callback、清理节点。
   - 边界：超时、错误处理、callback 名冲突。

2. 手写请求签名
   - 考点：参数排序、时间戳、nonce、防重放。
   - 边界：签名字段排除、编码一致性。

3. 手写刷新 token 队列
   - 考点：请求拦截、401 处理、队列重放。
   - 边界：并发 401 只刷新一次、刷新失败登出。

4. 手写接口缓存
   - 考点：缓存 key、过期策略、强制刷新。
   - 边界：用户维度隔离、缓存污染。

5. 手写断网重连
   - 考点：online/offline 事件、重试队列。
   - 边界：指数退避、最大重试次数。

6. 手写 SSE 客户端封装
   - 考点：EventSource、消息分发、重连。
   - 边界：鉴权、心跳、服务端关闭。

7. 手写 WebSocket 客户端封装
   - 考点：连接、心跳、重连、消息订阅。
   - 边界：重复连接、页面隐藏、消息积压。
