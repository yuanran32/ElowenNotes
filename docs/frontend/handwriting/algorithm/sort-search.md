# 排序与查找

1. 快速排序
   - 考点：分区、递归、原地排序。
   - 复杂度：平均 O(n log n)，最坏 O(n^2)。

2. 归并排序
   - 考点：分治、合并有序数组。
   - 复杂度：时间 O(n log n)，空间 O(n)。

3. 堆排序
   - 考点：建堆、下沉、原地排序。
   - 复杂度：时间 O(n log n)，空间 O(1)。

4. 二分查找
   - 考点：边界条件、左右闭区间或左闭右开区间。
   - 复杂度：时间 O(log n)。

5. 搜索旋转排序数组
   - 考点：二分变形、有序半区判断。
   - 复杂度：时间 O(log n)。
