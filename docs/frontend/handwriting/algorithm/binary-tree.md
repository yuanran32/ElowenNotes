# 二叉树

1. 二叉树前序遍历
   - 考点：递归、栈迭代。

2. 二叉树中序遍历
   - 考点：递归、栈迭代。

3. 二叉树后序遍历
   - 考点：递归、双栈、反向前序。

4. 二叉树层序遍历
   - 考点：队列、按层收集。

5. 二叉树最大深度
   - 考点：DFS、BFS。

6. 判断对称二叉树
   - 考点：递归比较、队列比较。

7. 二叉树最近公共祖先
   - 考点：递归返回、搜索路径。

8. 路径总和
   - 考点：DFS、回溯。

9. 二叉搜索树第 K 小
   - 考点：中序遍历有序。

10. 重建二叉树
    - 考点：前序中序、哈希定位根节点。
