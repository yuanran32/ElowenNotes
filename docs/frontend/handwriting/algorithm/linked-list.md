# 链表

1. 合并两个有序链表
   - 考点：虚拟头节点、递归或迭代。
   - 复杂度：时间 O(m+n)，空间 O(1) 或递归 O(m+n)。

2. 反转链表
   - 考点：三指针移动、递归。
   - 复杂度：时间 O(n)，空间 O(1)。

3. 判断链表是否有环
   - 考点：快慢指针。
   - 复杂度：时间 O(n)，空间 O(1)。

4. 找到环形链表入口
   - 考点：快慢指针相遇后重置。
   - 复杂度：时间 O(n)，空间 O(1)。

5. 删除链表倒数第 N 个节点
   - 考点：双指针、虚拟头节点。
   - 复杂度：时间 O(n)，空间 O(1)。

6. 判断回文链表
   - 考点：快慢指针、反转后半段。
   - 复杂度：时间 O(n)，空间 O(1)。
