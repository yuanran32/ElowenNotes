# 动态规划与搜索

1. 爬楼梯
   - 考点：滚动变量。
   - 复杂度：时间 O(n)，空间 O(1)。

2. 零钱兑换
   - 考点：完全背包。
   - 复杂度：时间 O(amount * coins.length)。

3. 最长递增子序列
   - 考点：动态规划、贪心加二分。
   - 复杂度：二分解法 O(n log n)。

4. 最长公共子序列
   - 考点：二维 DP。
   - 复杂度：时间 O(mn)，空间 O(mn) 可优化。

5. 编辑距离
   - 考点：插入、删除、替换三种转移。
   - 复杂度：时间 O(mn)。

6. 岛屿数量
   - 考点：DFS、BFS、访问标记。
   - 复杂度：时间 O(mn)。

7. 组合总和
   - 考点：回溯、剪枝、重复选择。

8. 全排列
   - 考点：回溯、使用标记数组。
