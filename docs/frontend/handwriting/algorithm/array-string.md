# 数组与字符串

1. 两数之和
   - 考点：哈希表、一次遍历。
   - 复杂度：时间 O(n)，空间 O(n)。

2. 三数之和
   - 考点：排序、双指针、去重。
   - 复杂度：时间 O(n^2)，空间 O(1) 到 O(n)。

3. 合并两个有序数组
   - 考点：双指针、原地合并。
   - 复杂度：时间 O(m+n)，空间 O(1)。

4. 最长不重复子串
   - 考点：滑动窗口、哈希表。
   - 复杂度：时间 O(n)，空间 O(k)。

5. 最长回文子串
   - 考点：中心扩展、动态规划。
   - 复杂度：中心扩展时间 O(n^2)，空间 O(1)。

6. 最大子数组和
   - 考点：动态规划、贪心。
   - 复杂度：时间 O(n)，空间 O(1)。

7. 买卖股票最佳时机
   - 考点：维护最低价格、最大利润。
   - 复杂度：时间 O(n)，空间 O(1)。

8. 有效括号
   - 考点：栈、括号映射。
   - 复杂度：时间 O(n)，空间 O(n)。

9. 字符串全排列
   - 考点：回溯、去重。
   - 复杂度：时间 O(n!)。

10. 子集
    - 考点：回溯、选择与撤销。
    - 复杂度：时间 O(2^n)。
