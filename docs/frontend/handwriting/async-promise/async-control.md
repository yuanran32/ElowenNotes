# 异步控制

1. 手写 `sleep`
   - 考点：Promise 封装 `setTimeout`。
   - 边界：定时器清理。

2. 手写请求超时控制
   - 考点：`Promise.race`、超时错误。
   - 边界：请求完成后清理 timer。

3. 手写可取消 Promise
   - 考点：取消标记、`AbortController`。
   - 边界：取消后不要继续触发状态更新。

4. 手写 `retry`
   - 考点：失败重试、最大次数、延迟间隔。
   - 边界：只对可重试错误重试。

5. 手写指数退避重试
   - 考点：退避时间、最大延迟、随机抖动。
   - 边界：避免同一时间大量重试。

6. 手写异步串行执行
   - 考点：`for...of await` 或 `reduce` Promise 链。
   - 边界：失败后是否中断。

7. 手写异步并行执行
   - 考点：`Promise.all` 收集结果。
   - 边界：失败策略，全部失败还是部分失败。

8. 手写异步任务调度器 `Scheduler`
   - 考点：任务队列、最大并发、完成后补位。
   - 边界：任务动态加入、异常释放并发槽。

9. 手写并发请求控制器
   - 示例：最多同时执行 3 个请求。
   - 考点：队列、并发上限、结果顺序。
   - 边界：中途失败是否继续调度。

10. 手写异步池 `asyncPool`
    - 考点：限制同时运行的 Promise 数量。
    - 边界：保留输入顺序、错误短路。

11. 手写红绿灯任务
    - 示例：红灯 3 秒、绿灯 2 秒、黄灯 1 秒循环。
    - 考点：递归异步流程、定时器。
    - 边界：停止循环、页面卸载清理。

12. 手写微任务调度器
    - 考点：`queueMicrotask`、Promise、MutationObserver fallback。
    - 边界：大量微任务导致渲染饥饿。
