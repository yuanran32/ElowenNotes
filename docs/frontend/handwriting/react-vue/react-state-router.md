# React 状态与路由

1. 手写简版 Redux
   - 考点：store、dispatch、subscribe、reducer。
   - 边界：状态不可变更新。

2. 手写 `connect`
   - 考点：订阅 store、映射 state、触发更新。
   - 边界：浅比较减少渲染。

3. 手写 Redux 中间件机制
   - 考点：洋葱模型、函数组合、dispatch 增强。
   - 边界：中间件顺序。

4. 手写简版 React Router
   - 考点：路由匹配、History API、Context。
   - 边界：动态参数、嵌套路由、刷新 404。

5. 手写 Error Boundary 示例
   - 考点：错误边界、降级 UI、生命周期。
   - 边界：不能捕获异步错误和事件处理器错误。

6. 手写受控表单组件
   - 考点：状态绑定、校验、提交、重置。
   - 边界：输入法合成事件。

7. 手写 React Modal
   - 考点：Portal、滚动锁定、焦点管理。
   - 边界：多层弹窗。

8. 手写 React 无限滚动列表
   - 考点：IntersectionObserver、分页加载。
   - 边界：重复请求、没有更多数据。
