# Vue 响应式

1. 手写 Vue2 响应式
   - 考点：`Object.defineProperty`、依赖收集、派发更新。
   - 边界：新增属性、数组变更拦截。

2. 手写 Vue3 响应式
   - 考点：Proxy、Reflect、依赖收集、嵌套对象。
   - 边界：代理缓存、只读代理。

3. 手写 `ref`
   - 考点：`.value`、基本类型响应式。
   - 边界：对象值转 reactive。

4. 手写 `computed`
   - 考点：懒执行、缓存、依赖失效。
   - 边界：依赖变化后 dirty 标记。

5. 手写 `watch`
   - 考点：新旧值、立即执行、深度监听。
   - 边界：清理副作用、flush 时机。

6. 手写 `nextTick`
   - 考点：微任务、异步更新队列、回调收集。
   - 边界：环境降级。

7. 手写事件总线
   - 考点：发布订阅、组件通信、销毁解绑。
   - 边界：避免全局事件泄漏。
