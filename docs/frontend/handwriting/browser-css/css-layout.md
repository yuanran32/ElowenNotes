# CSS 布局

1. 实现水平垂直居中
   - 考点：flex、grid、absolute + transform、table-cell。
   - 边界：未知宽高、文本多行。

2. 实现两栏布局
   - 考点：固定侧边栏、自适应主区域。
   - 边界：侧边栏收起、主区域最小宽度。

3. 实现三栏布局
   - 考点：圣杯布局、双飞翼布局、flex、grid。
   - 边界：中间栏优先渲染。

4. 实现等高布局
   - 考点：flex stretch、grid。
   - 边界：内容超长滚动。

5. 实现粘性页脚
   - 考点：视口高度、flex column。
   - 边界：内容不足贴底，内容超出自然撑开。

6. 实现 1px 边框
   - 考点：设备像素比、transform scale、伪元素。
   - 边界：圆角、不同 DPR。

7. 实现三角形
   - 考点：border 绘制、透明边框。
   - 边界：方向和尺寸控制。

8. 实现多行文本省略
   - 考点：`line-clamp`。
   - 边界：兼容性、纯 CSS 降级。

9. 实现响应式栅格
   - 考点：media query、CSS grid、`minmax`、`auto-fit`。
   - 边界：极窄屏幕。

10. 实现瀑布流布局
    - 考点：CSS columns、grid masonry、JS 计算列高。
    - 边界：图片加载后高度变化。

11. 实现移动端适配
    - 考点：rem、vw、viewport、设计稿换算。
    - 边界：横屏、平板、字体缩放。

12. 实现暗黑模式
    - 考点：CSS 变量、`prefers-color-scheme`、主题持久化。
    - 边界：系统主题变化监听。

13. 实现骨架屏
    - 考点：渐变动画、占位结构。
    - 边界：减少布局偏移。

14. 实现无障碍 Modal
    - 考点：焦点管理、ESC 关闭、遮罩点击、滚动锁定、ARIA。
    - 边界：多层弹窗、焦点恢复。
