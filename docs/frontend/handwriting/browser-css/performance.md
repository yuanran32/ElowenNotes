# 性能工具

1. 手写防抖 `debounce`
   - 考点：延迟执行、清除定时器、保留参数和 `this`。
   - 边界：立即执行、取消、flush。

2. 手写节流 `throttle`
   - 考点：时间戳版本、定时器版本。
   - 边界：首尾触发配置。

3. 手写 `requestAnimationFrame` 节流
   - 考点：浏览器渲染帧、滚动事件优化。
   - 边界：页面隐藏时 RAF 降频。

4. 手写图片懒加载
   - 考点：`IntersectionObserver`、占位图。
   - 边界：不支持时降级滚动监听。

5. 手写虚拟列表
   - 考点：可视区域计算、滚动偏移、占位高度。
   - 边界：动态高度、快速滚动、滚动恢复。

6. 手写大文件分片上传
   - 考点：Blob 切片、并发上传、合并请求。
   - 边界：断点续传、失败重试、秒传。

7. 手写前端缓存封装
   - 考点：localStorage、过期时间、序列化。
   - 边界：容量超限、隐私模式、降级内存缓存。

8. 手写性能埋点 SDK
   - 考点：PV、UV、资源性能、接口耗时。
   - 边界：批量发送、失败重试、页面卸载上报。

9. 手写错误监控
   - 考点：`window.onerror`、`unhandledrejection`、资源错误。
   - 边界：跨域脚本错误、重复上报、source map 还原。
