# 组件类

1. 实现一个支持搜索、分页、排序的表格组件
   - 考点：状态设计、受控参数、异步请求、空态、loading。
   - 追问：分页和搜索同时变化时如何避免重复请求？

2. 实现一个可拖拽排序列表
   - 考点：拖拽事件、占位元素、排序更新、移动端兼容。
   - 追问：数据量很大时如何减少重排？

3. 实现一个图片上传组件
   - 考点：格式校验、大小校验、预览、进度、失败重试。
   - 追问：如何支持断点续传和秒传？

4. 实现一个树形选择器
   - 考点：递归渲染、半选状态、父子联动、搜索过滤。
   - 追问：节点数量过万时如何优化？

5. 实现一个表单校验器
   - 考点：规则配置、异步校验、错误收集、触发时机。
   - 追问：字段联动校验怎么做？

6. 实现一个多步骤向导
   - 考点：步骤状态、表单缓存、前后切换、提交汇总。
   - 追问：中途刷新如何恢复进度？

7. 实现一个消息通知中心
   - 考点：队列、自动关闭、手动关闭、堆叠展示。
   - 追问：同类消息如何合并？

8. 实现一个 Markdown 编辑器
   - 考点：输入同步、预览渲染、XSS 防护、快捷键。
   - 追问：大文档编辑如何避免卡顿？
