# 系统类

1. 实现一个前端权限系统
   - 考点：路由权限、按钮权限、菜单过滤、动态路由。
   - 追问：刷新页面后权限怎么恢复？

2. 实现一个低代码拖拽画布
   - 考点：组件协议、拖拽定位、选中态、属性面板、撤销重做。
   - 追问：组件 schema 如何设计？

3. 实现一个埋点 SDK
   - 考点：事件采集、批量上报、失败重试、离线缓存。
   - 追问：页面关闭前如何保证上报？

4. 实现一个错误监控 SDK
   - 考点：JS 错误、Promise 错误、资源错误、接口错误。
   - 追问：如何用 source map 还原线上报错？

5. 实现一个微前端加载器
   - 考点：应用注册、资源加载、沙箱隔离、生命周期。
   - 追问：样式隔离和全局变量污染怎么处理？

6. 实现一个前端灰度发布方案
   - 考点：用户分流、配置下发、版本回滚。
   - 追问：如何保证灰度命中稳定？

7. 实现一个国际化方案
   - 考点：词条管理、动态加载、插值、复数。
   - 追问：构建时和运行时国际化怎么取舍？
