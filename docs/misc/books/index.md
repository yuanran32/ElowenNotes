# 读书笔记

用于沉淀书籍阅读记录。这里不追求完整摘抄，重点是把书里的观点转成自己的判断、案例和行动清单。

## 分类建议

1. 技术类：软件工程、架构、性能、测试、数据结构。
2. 协作类：沟通、管理、写作、项目推进。
3. 思维类：决策、认知、学习方法。
