# 面试杂项

这里放不属于具体技术栈的面试内容，例如 HR 面、行为面、沟通表达、面试复盘和公司信息整理。

技术题如果能归入前端、后端、算法，应优先放到对应目录。

## 内容范围

1. HR 面常见问题。
2. 行为面 STAR 素材。
3. 面试后复盘。
4. 公司、岗位、业务线信息整理。
5. 自我介绍、离职原因、职业规划。
