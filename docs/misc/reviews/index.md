# 问题复盘

用于记录 Bug、线上事故、排查过程、性能问题和踩坑经验。复盘不是记流水账，重点是让同类问题以后更快定位或避免。

## 适合放这里的内容

1. 本地环境问题排查。
2. 构建、部署、依赖、版本冲突问题。
3. 线上异常、性能劣化、兼容性问题。
4. 一次问题暴露出的流程或认知缺口。

## 复盘模板

```md
# 问题标题

## 背景

## 现象

## 影响范围

## 排查过程

## 根因

## 解决方案

## 如何避免再次发生

## 可复用排查清单
```

## 命名建议

- 普通问题：`YYYY-MM-DD-title.md`
- 线上问题：`incident-YYYY-MM-DD-title.md`
- 环境问题：`env-YYYY-MM-DD-title.md`
